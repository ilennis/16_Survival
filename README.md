# 16 DAYS

16조의  공포, 좀비 서바이벌

## 게임 개요 - "당신은 정체불명의 병에 감염되었습니다. 이 병을 치료하려면 백신이 필요합니다. 탐사를 통해 얻은 약재를 조합하면 백신을 만들 수 있습니다. 살아남기 위해 백신을 찾아야 합니다."

조작키

          - 이동 : WASD

         - 채집 :  F

         - 인벤토리 열기 : I 

         - 공격,나무베기 : 마우스 왼쪽 버튼 

         - 무기 변경 : 번호 눌러서 변경

         - 식사 : 인벤토리에서 사용

         - 가공 : 가공UI에서

구현 사항 

(필수)

          - 자원 수집 및 가공

         - 식사와 수분 관리

         - 건축 및 생존 기지 구축

         - 적과의 전투

         - 생존 관리 시스템

         - 자원 리스폰

(도전) 

         - 날씨와 환경 요소

        - 고급 건축 시스템

        - 다양한 적 종류

        - 크래프팅 시스템

        - 퀘스트와 스토리

        - 고급 AI 시스템

        - 사운드 및 음악
